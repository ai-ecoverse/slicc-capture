# slicc-capture

`@ai-ecoverse/slicc-capture`: `screencapture` and `sccapture` for SLICC, where seven's page captures with `getDisplayMedia` after a prompt, and `sccapture` for hosts as Node in `host/` over `screencapture`, grim, gnome-screenshot, `import`, scrot or PowerShell. README.md is the spec: every macOS `screencapture` option is in its table. No comments in any file. No CLAUDE.md. Unit tests live in the gitignored `test/unit/` (`npm run test:unit` writes coverage to `coverage/unit/lcov.info`; the pre-commit hook wants 100% of changed lines); committed tests in `test/integration/`. Host tests use fake tools on `PATH`; only CI touches a real screen. CI is `ci.yml` on slicc-shared-web's pipeline. `npm run lint` and `npm test` must pass. Never use ports 9222-9229. Releases come from `main` via semantic-release; never move or delete a pushed tag.
